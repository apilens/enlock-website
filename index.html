what's on the tape

Your app already knows why it crashed.
slomo kept the recording.

Everything below happens automatically after enable(). No agents, no sidecars, no YAML.

sys.monitoring · PEP 669

Zero-config auto-trace

Every call in your code — args, results, durations, exceptions. Stdlib and third-party frames are disabled inside the interpreter, so they cost nothing.

import slomo slomo.enable() # that's the whole integration ✓ recording to .slomo/ — FastAPI, Flask, asyncio, threads
locals

Crashes with variables

Tracebacks arrive with the local variables of every crashing frame — even from worker threads and the 500s your framework swallows.

TypeError in checkout() inventory = None ← captured sku = 'gadget'
timeline

SQL + HTTP + logs, correlated

Queries, requests, and log records land on the same timeline as your function calls.

sql.query SELECT qty FROM… sql.result 0 rows, 9µs http.post /api/charge 402
issues

Deduped, not duplicated

Crashes are fingerprinted: the same bug tomorrow is occurrences += 1, not a new alert. Category, severity, stability — automatic.

doctor

Root cause, named

slomo doctor points at the first bad function, the first bad variable, and a suggested fix — with evidence.

replay

Time-travel in your terminal

Step through the recording event by event. Jump, search, inspect variables at any point in time.

[11/12] return load_inventory → None ← the smoking gun [12/12] raise TypeError in checkout, app.py:14
local-first

Private by construction

Everything lives in .slomo/ inside your repo. Secrets — tokens, keys, cards — are redacted at capture time. They never touch disk, and nothing ever leaves your machine.

password = [REDACTED] api_key = [REDACTED] ← before write, not after

get started

Recording in three steps.

01

Install

$ pip install slomo

Python 3.12+. The recorder's hot path is stdlib-only.

02

Enable

import slomo
slomo.enable()

Works as-is with FastAPI, Flask, asyncio, workers. Want more depth? @track.

03

Interrogate

$ slomo issues
$ slomo doctor SM-8b6f710a
$ slomo replay SM-8b6f710a

Plus live timeline --follow, full-text search, and exports.
