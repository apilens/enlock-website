What it does

Everything on tape. Nothing in the way.

enable()

Zero-config auto-trace

One line records every function call in your code — args, results, durations, exceptions — via sys.monitoring (PEP 669). Stdlib and third-party frames are switched off inside the interpreter, so they cost nothing.

locals

Crashes with variables

Unhandled exceptions are captured with structured tracebacks and the local variables of every crashing frame — including worker threads and the 500s your web framework swallows.

timeline

SQL, HTTP & logs, correlated

Queries (sqlite3, SQLAlchemy), HTTP calls (requests, httpx), and log records land on the same timeline as your function calls — so you see what led up to the crash.

issues

Issues, not noise

Crashes are fingerprinted and deduplicated: the same bug tomorrow is occurrences += 1, not a new alert. Each issue gets a category, severity, and stability rating automatically.

doctor

Root-cause diagnosis

slomo doctor names the first bad function, the first bad variable, and a suggested fix — with the events just before the crash as evidence.

replay

Time-travel replay

slomo replay steps through the recording event by event — jump, search, and inspect variables at any point, entirely in your terminal.

local

Local-first & private

Everything lives under .slomo/ in your project. No server, no account, no telemetry. Secrets (tokens, keys, cards) are redacted at capture time — they never touch disk.

<5ms

Never breaks your app

enable() in under 5 ms (enforced by a test). Hooks are exception-isolated, writes are batched and crash-safe append-only JSONL — a kill -9 loses at most one line.

Get started

Recording in three steps.

Step 1 — install

One package, no services

$ pip install slomo

Python 3.12+. The recorder's hot path is stdlib-only.

Step 2 — enable

Add one line to your app

import slomo
slomo.enable()   # that's the whole integration

Works as-is with FastAPI, Flask, asyncio, and background workers. Want more depth? Decorate hot spots with @track.

Step 3 — investigate

Ask the tape when it breaks

$ slomo issues        # crashes, deduped
$ slomo doctor ISSUE  # root cause
$ slomo replay ISSUE  # step through it

Plus timeline --follow, full-text search, typed sql/http/vars views, and exports.
